# 어항 배경 그래픽 개선 기록

2026-10-17. 개발 전달 문서 9절과 10절의 ‘기본 어항 장면 개선’에 해당하는 범위를 구현했다.

## 1단계 · 자연 어항 장면

청록색 수심 그라데이션, 대비를 낮춘 후경 수초, 왼쪽 유목·바위, 불규칙한 모래 입자와 접지 그림자, 가장자리의 작은 전경 수초를 적용했다. 중앙을 비워 물고기가 읽히도록 했다. PC 전용으로 배경을 덮어쓰던 스타일을 제거해 미리보기와 대시보드, PC와 모바일에서 같은 장면을 사용한다.

내장 image_gen 도구로 생성한 투명 에셋 두 개는 `public/assets/aquarium/natural/driftwood-v1.webp`, `plant-v1.webp`에 저장했다. 생성 조건과 최종 프롬프트는 같은 폴더의 [ASSETS.md](../../public/assets/aquarium/natural/ASSETS.md)에 기록했다. 모래 입자 SVG는 고정 난수 시드 20261017로 작성한 작은 정적 벡터 타일이다.

## 2단계 · 앞뒤 장식과 편집

장식에 선택적 `layer: "back" | "front"`를 추가했다. 기존 저장값은 후경으로 표시한다. 서버 검증, 클라이언트 읽기, 설정 화면을 함께 수정했으며 기존 `decorations_json`을 사용하므로 DB 스키마 변경은 없다. 서버 검증 코드는 백엔드를 다시 시작하면 반영된다.

설정 화면은 Aquarium에서 장식을 직접 렌더링하고 투명한 편집 핸들만 위에 겹친다. 장식 선택 목록, 앞뒤 레이어, 위치·크기 슬라이더로 키보드와 터치 편집을 지원한다. 새로운 자연 에셋을 추가 장식으로도 선택할 수 있다.

물고기와 상태 말풍선의 표시 순서를 분리했다. 전경은 물고기를 일부 가릴 수 있지만 말풍선은 전경 위에 표시한다. 이 앞뒤 배치는 장면 연출이며 실제 물고기의 깊이 측정 결과가 아니다.

## 3단계 · 움직임과 표시 비용

기포는 두 지점에서 올라오며 ResizeObserver로 측정한 어항 높이에 맞춰 수면까지 이동한다. 크기 자체를 기준으로 이동하던 문제를 해결했다. 수초는 밑동을 기준으로 서로 다른 주기·위상으로 약하게 흔들린다.

전체 화면 SVG 노이즈와 SMIL을 제거하고 바닥에만 가벼운 CSS 빛 무늬를 적용했다. 실제 물고기를 자식으로 받는 화면에서 불필요하게 실행되던 배경 컴포넌트의 임의 수영 렌더 루프도 중단했다. ‘움직임 줄이기’에서는 배경 애니메이션과 기포를 멈춘다. 센서의 기존 정상·주의·위험 판정은 유지하며 배경 색 변화만 완화했다.

## 확인 결과

- `npm run build`, `npm test`, `node --check server.cjs`, `git diff --check` 통과.
- 새 서버 테스트: 레이어 없는 기존 데이터, 앞뒤 레이어 저장, 계정 분리, 잘못된 레이어 거절, 빈 배치 저장.
- Chromium에서 API·WebSocket 모의 응답을 사용해 1440px·800px·390px 미리보기와 1440px·390px 대시보드를 검증했다.
- 레이어 저장 후 새로고침 복원, 장식 삭제·추가, 위치·크기 입력, 에셋 로드, 리사이즈 후 기포 이동 거리, 움직임 줄이기, 가로 넘침 없음, 브라우저 실행 오류 없음을 확인했다.
- 실기기 FPS, 실제 센서·카메라 연결, 운영 서버 저장은 이번 로컬 검증에 포함하지 않았다. 물고기 리깅·AI 입력 안정화·원근 효과는 이번 배경 작업 범위에 포함하지 않았다.
