# 정지 움직임·원근 표현 조정

2026-10-18. 기존 작업 내용을 유지하고 물고기 표시 관련 코드만 추가 조정했다.

## 변경

- 정지 시 큰 꼬리 왕복 대신 느리고 작은 지느러미 움직임을 남겼다. 기본 위상 속도는 4.1에서 1.8rad/s로 줄였다.
- 작은 속도 노이즈는 수영 강도를 올리지 않는다. 실제 이동에서는 강도와 주기가 함께 증가하고, 정지하면 서서히 가라앉는다. 위치에 임의 이동이나 상하 부유를 추가하지 않았다.
- 중복된 활동량 표시 보간을 줄이고 렌더러에서 가속·감속을 연결한다. 패킷과 속도 변화가 위상을 초기화하지 않는다.
- 지느러미 선택 영역의 경계까지 고정하던 가중치를 바꿔 자유로운 가장자리도 움직이게 했다. 주변은 작은 범위로 부드럽게 연결하고 몸통 보호·부착점은 유지한다. 꼬리와 지느러미 끝에 위상 지연을 적용했다.
- 좌우 전환 중에는 표시 방향에 맞는 기울기만 적용하며, 시작한 전환 방향을 중간 패킷이 즉시 되돌리지 않게 했다.
- 기존 높이 기반 깊이 배율 0.90~1.10은 유지한다. 가장 멀 때 채도 0.82·대비 0.86·밝기 0.955로 물속 거리감을 조금 보강했다. 블러는 추가하지 않았다.

## 검증

- `npm test`: 전체 8개 테스트 파일 통과. 새 움직임 테스트 6개는 정지/수영 구분, 감속·위상 연속성, 몸통·부착선 고정, 좌우 대칭, 전환 중 방향 갱신, 깊이 색감의 범위를 확인한다.
- `npm run build`: 타입 검사·프로덕션 빌드 통과. 기존 Three 번들의 500kB 안내는 남아 있다.
- Chromium과 소프트웨어 WebGL, 모의 API·추적 입력으로 1440px·390px 화면을 확인했다. 중심 고정, 후퇴 배율 약 0.90, 전환 중 캔버스 유지, 가로 넘침 없음, WebGL 유실 시 원본 이미지 표시를 확인했다. 페이지 오류와 서버 변경 요청은 없었다.
- 기본 리그의 한 꼬리 지점 `(0.30, 0.55)`에서 400개 위상 샘플을 비교했다. 정지 최대 변위는 정규화 이미지 좌표 기준 약 0.005493→0.001319였다. 특정 지점의 합성 계산이며 전체 그래픽이나 실물 물고기의 개선율이 아니다.

## 확인 범위

실제 어항 영상이나 이번 세션의 실시간 추적 패킷을 사용한 검증은 아니다. `bbox`와 `frame_size`가 없거나 자세·가림 조건이 불안정하면 깊이는 갱신되지 않는다. 이때 임의로 크기를 반복 변경해 앞뒤 이동을 만들지 않는다. 실제 송신기가 두 필드를 전달하는지는 운영 입력에서 확인해야 한다. 운영 배포·서버 재시작은 수행하지 않았다.
